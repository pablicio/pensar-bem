# Materiais dos livros de tecnologia

Pacotes para o aluno acompanhar os livros: código dos exemplos,
projeto quando existe, snapshots quando o mesmo arquivo muda, e o
Docker de ambiente. Mensageria One fica para depois.

Esta pasta é o conteúdo do repositório dos materiais.
Os zips para download ficam em `zips/`.

Gerar de novo:

```
.venv\Scripts\python.exe scripts\montar_materiais_livros.py
```
